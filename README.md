# AutoResearch Workspace Tools

完整题目包校验、双 Agent 长跑、监护和回收统一执行 [双 Agent 长跑与题包验收规范](双Agent长跑与题目包验收规范.md)，必须使用工作区官方任务 Agent 控制器、GPU 调度器和监控工具，不得自建替代控制链。

本仓库保存 AutoResearch 工作区的通用工具、运行治理脚本、质量规范和协作文档。

仓库范围仅保留可复用的源码和文档：

- `tools/`：GPU 监控、GPU 调度和长程研究接管工具的源码与使用说明。
- `ops/`：通用运维辅助脚本。
- `notes/`：可复用的运行、资源、目录和交付规范文档。
- `materials/`：项目培训、专家教程和 QA 技能资料，不包含具体题目包或测试数据。
- 根目录 Markdown 文档：工作区协作和全流程规范。

具体题目目录、交付包、实验模型与数据、运行证据、缓存、测试目录和本机凭据均不纳入版本库。运行工具前请按本机环境和题目目录中的真实授权、路径与资源合同核对配置。
